2. 以固定航向航向
3. 不同起飞点摆放
4. 不同航向摆放

### 科目一

## 执行说明

已添加 `config/mission/test_1114_a.xml`、`test_1114_b.xml` 及对应
`launch/test_1114_a.launch`、`test_1114_b.launch`。
专用配置为 `config/test_1114.yaml`，速度上限 1 m/s、加速度上限
0.5 m/s²、全球水平到达容差 1 m；均需根据现场定位精度确认。

### 科目零：现场测量与记录

1. 在静止状态检查 `/mavros/global_position/global`、
   `/mavros/global_position/rel_alt` 和 `/mavros/local_position/pose`，
   确认持续更新、定位有效；记录目标点多次经纬度读数及波动范围。
   GPS 读数不能代替精确测量，需要精确定位时使用现场测量设备。
2. 记录起飞点、目标点、机头方向和 local pose 的四元数。
   local 航向由 `atan2(2(wz+xy), 1-2(y²+z²))` 换算为度。
3. `nav/azimuth_angle` 使用原始 local 坐标 +X 为 0°、朝 +Y 为正。
   若已确认 local 坐标与 ENU 对齐，则地理方位角（北为 0°、顺时针）
   转为该参数的公式为 `90° - 方位角`，归一化到 [-180°, 180°]。
   未确认对齐时须先测量 local 方向偏差，不能直接套用地理航向。
4. 将实测目标纬度、经度写入 A XML 的 `latitude`、`longitude`，
   将期望航向写入专用 YAML 的 `nav/azimuth_angle`。
   A XML 当前是仿真示例坐标，不能直接用于现场。

### 科目一：固定经纬度

起飞至 local 高度增加 3 m → 飞向固定经纬度并调整到配置航向 →
悬停 5 s → 返回本次起飞点上方 → 降落。
每轮改变起飞位置，保持目标经纬度和配置航向一致，记录到达误差。
NavGeo 保持当前 local Z，不使用 GPS 海拔作为目标高度。

### 科目二：固定航向航行

将计划中的“以固定航向航向”按“以固定航向航行”执行：
起飞 3 m → 调整到配置航向 → 以当前位置为基点沿该方向前进 5 m →
悬停 5 s → 返回起飞点上方 → 降落。
每轮改变初始机头摆放角度，保持配置航向不变，记录航向及轨迹偏差。
距离在 B XML 的 `nav_n` 修改，`nav_t=0` 表示无侧向位移。

### 启动与结果记录

仿真（每次只运行一个科目）：

```bash
roslaunch maxt_pkg test_1114_a.launch
roslaunch maxt_pkg test_1114_b.launch
```

实机使用 `sim:=false`；若 MAVROS 尚未启动，额外指定 `run_uav:=true`。
启动任务前完成现场参数修改及起飞前检查，任务节点会执行起飞流程。
记录每次起飞位置、摆放角度、目标经纬度、配置航向、实测到达位置、
航向误差、返航落点及异常。节点失败会使 Sequence 停止，
该任务没有自动故障返航分支；现场须确认遥控接管与飞控失效处理。
`nav/hold_timeout` 可能使末端对齐超时后返回成功，因此须以实际误差
评估试飞结果，不能仅凭行为树 SUCCESS 判定精度合格。
