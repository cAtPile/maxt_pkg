# Supreme Principle

## 项目最核心的准则

1. 假设输入输出的内容经过严格校验的无需过度防御性开发
2. 不做破坏性的更新,修改某个模块时，不动其他模块的内容
3. 新增的模块要插入些必要的注释
4. 尽量复用已有的函数
5. 更新README.md
6. 保持人的可读性，不要过度压行
7. 不修改 _guide.md文件  
8. 不需要做无意义的test，测试由我亲自进行
9. 做最小修改原则

## 标准性规范
1. 每个节点单独建立文件
2. ##实现方式 是新增模块的实现方式描述
3. ##修改意见 如果是修改的指令，主要完成本部分
4. 如果后缀是_modify 请直接完成##修改意见 无需再次实现##实现方式
